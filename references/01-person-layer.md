# 01 · 人物建模通用层（双层架构 + 演化/回滚）

colleague（同事）开创了"把人蒸馏成 AI Skill"的双层架构，nuwa（女娲）与 yourself（自己）
都建立在这一地基之上。本文件定义人物类蒸馏的**通用层**，各模式在其上叠加特定模块。

## 双层架构

```
Persona（人格层，通用基础）
   ├── 硬规则 hard rules      —— 绝对不做的底线
   ├── 身份 identity          —— 我是谁、角色定位
   ├── 表达 expression        —— 语气、节奏、用词偏好（表达 DNA）
   ├── 决策 decisions         —— 怎么判断、决策启发式
   ├── 人际 interpersonal     —— 怎么与人互动
   └── 纠正 Correction        —— 对话纠偏层（即时生效）
        │
        ├── [colleague] 叠加 Work Skill（技术能力 / 代码习惯 / Review 风格）
        ├── [nuwa]      叠加 心智模型 + 价值观与反模式 + 诚实边界
        └── [yourself]  叠加 Self Memory（自我记忆）
```

> nuwa 把它细化为"五层心智模型"：怎么说话 / 怎么想 / 怎么判断 / 什么不做 / 知道局限。
> yourself 把它细化为"5 层人格结构"：硬规则 → 身份 → 说话风格 → 情感模式 → 人际行为。
> 三者本质一致，只是命名与侧重不同，正流统一用上面的 6 槽位。

## 演化机制（三个模式共用）

- **追加数据（Append）**：新聊天记录/文档进来 → 自动分析增量 → **merge 进对应部分，不覆盖已有结论**。
- **对话纠正（Correction）**：用户说"我不会这样说" → 写入 Correction 层，**立即生效**。
- **版本管理（Version）**：每次更新自动存档，支持**回滚**到历史版本。

实现参考 `scripts/` 中的 `skill_writer` 思路与 `version_manager` 思路（yourself-skill 提供了 Python 原版）。

## 诚实边界（人物类必写）

每个产物必须声明：
- 蒸馏不了直觉/灵感（框架能提取，灵感不能）；
- 捕捉不了突变（截至调研时间的快照）；
- 公开表达 ≠ 真实想法（仅 nuwa 涉及公开人物时强调）；
- 还原的是被蒸馏时的那个对象，对象会变化。

## 输入数据源优先级（通用建议）

- colleague：自身长篇写作（设计文档/评审）＞ 决策回复 ＞ 群聊
- yourself：深夜对话/独白 ＞ 情绪波动记录 ＞ 做决定的聊天 ＞ 日常闲扯
- nuwa：第一人称书/博客/长访谈 ＞ 决策记录 ＞ 验证过的短帖 ＞ 第三方评论

> 原材料质量 = 产物质量。喂错数据直接降级。
