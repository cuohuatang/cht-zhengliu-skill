# 04 · 自己模式（yourself-skill）

上游：[notdog1998/yourself-skill](https://github.com/notdog1998/yourself-skill)。
**定位**：与其蒸馏别人，不如蒸馏自己——生成含自我记忆 + 5 层人格结构的数字分身。

## 设计哲学

最该被蒸馏的，其实是你自己：你才是那个 24 小时在线、跟你对话最多的人。
它把视角从"他人"内转到"自己"，致敬 colleague-skill 的双层架构。

## 生成的 Skill 结构（Part A + Part B）

| 部分 | 内容 |
| --- | --- |
| **Part A — Self Memory（自我记忆）** | 个人经历、核心价值观、生活习惯、重要记忆、人际关系、成长轨迹 |
| **Part B — Persona（人格模型）** | 5 层性格结构：硬规则 → 身份 → 说话风格 → 情感模式 → 人际行为 |

运行逻辑：`收到消息 → Persona 判断你会怎么回应 → Self Memory 补充个人背景和价值观 → 用你的方式输出`

## 数据源与解析器（开箱即用）

| 来源 | 格式 | 备注 |
| --- | --- | --- |
| 微信聊天记录 | WeChatMsg / 留痕 / PyWxDump 导出 | 推荐，重点提取"我"说的话 |
| QQ 聊天记录 | txt / mht 导出 | 适合学生时代的自己 |
| 社交媒体 / 日记 | 截图 / Markdown / TXT | 提取价值观和表达风格 |
| 照片 | JPEG/PNG（含 EXIF） | 提取时间线和地点 |
| 口述 / 粘贴 | 纯文本 | 你的自我认知 |

对应解析器（Python）：`wechat_parser.py` / `qq_parser.py` / `social_parser.py` /
`photo_analyzer.py`，外加 `skill_writer.py`（Skill 文件管理）、`version_manager.py`（版本存档与回滚）。

## 支持的标签

- **性格**：话痨 · 闷骚 · 嘴硬心软 · 冷暴力 · 社恐 · 独立 · 浪漫主义 · 实用主义 · 完美主义 ·
  没有安全感 · 秒回选手 · 已读不回 · 报复性熬夜 · 深夜 emo 型 · 纠结体 · 行动派 · 计划狂
- **生活习惯**：早起困难户 · 咖啡依赖 · 极简主义 · 囤积癖 · 数字游民 · 居家派 · 城市漫游者 · 仪式感狂热者
- **MBTI**：16 型全支持；**星座**：十二星座全支持。

## 进化机制

- **追加记忆** → 找到更多聊天记录/日记/照片 → 自动分析增量 → merge 进对应部分。
- **对话纠正** → 说"我不会这样说" → 写入 Correction 层，立即生效。
- **版本管理** → 每次更新自动存档，支持回滚。

## 管理命令（Claude Code 示例）

| 命令 | 说明 |
| --- | --- |
| `/create-yourself` | 创建自我 Skill |
| `/list-selves` | 列出所有自我 Skill |
| `/{slug}` | 调用完整 Skill（像你一样思考说话） |
| `/{slug}-self` | 自我档案模式（回忆/分析自己） |
| `/{slug}-persona` | 人格模式（仅性格和表达风格） |
| `/yourself-rollback {slug} {version}` | 回滚历史版本 |
| `/delete-yourself {slug}` | 删除 |

## 局限与注意

- **隐私风险最大**：喂的是自己的聊天记录/日记/照片，最敏感——建议本地存储、勿上传。
- 还原的是"被蒸馏时的那个自己"，人会变，snapshot 有时效性。
- runtime 覆盖最窄（仅 Claude Code / OpenClaw）。
- 依赖聊天记录导出工具（WeChatMsg / PyWxDump / 留痕），有系统门槛。
- 这是一个帮助你观察自己的工具，不是逃避现实的出口。

## 推荐优先提供的数据

1. 深夜对话/独白——最能暴露真实性格；
2. 情绪波动的记录——生气、难过、兴奋时的表达；
3. 做决定的聊天记录——暴露决策模式；
4. 日常闲扯——提炼口头禅和语气词。
