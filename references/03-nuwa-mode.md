# 03 · 女娲模式（nuwa-skill）

上游：[alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill)。
**定位**：蒸馏任何公开人物的"认知操作系统"——而不是只模仿说话风格。

## 为什么存在

同事.skill 证明了"蒸馏一个人可行"，但为什么只蒸馏身边的同事？去蒸馏各领域最强的人
（芒格、费曼、马斯克、纳瓦尔），他们通常留下了海量可被蒸馏的公开材料。

## 工作原理（输入一个名字后的四件事）

1. **六路并行采集**——著作、播客/访谈、社交媒体、批评者视角、决策记录、人生时间线，
   6 个 Agent 同时跑，各自存档（合计 40+ 信息源）。
2. **三重验证提炼**——一个观点要被收录为心智模型，必须同时满足：
   - 跨 **2+ 个领域**出现过（不是随口一说）；
   - 能**推断对新问题的立场**（有预测力）；
   - 不是所有聪明人都会这么想（有**排他性**）。
   三个都过才收录。
3. **构建 Skill**——3–7 个心智模型 + 5–10 条决策启发式 + 表达 DNA + 价值观与反模式 + 诚实边界。
4. **质量验证**——拿 3 个此人公开回答过的问题测试（方向一致才通过）；再用 1 个他没讨论过的问题
   测试（应表现适度不确定，而非斩钉截铁）。

## 五层心智模型（提取什么）

| 层次 | 说明 |
| --- | --- |
| 怎么说话 | 表达 DNA——语气、节奏、用词偏好 |
| 怎么想 | 心智模型、认知框架 |
| 怎么判断 | 决策启发式 |
| 什么不做 | 反模式、价值观底线 |
| 知道局限 | 诚实边界 |

> 工作习惯可以靠流程文档传递，但让芒格和马斯克面对同一问题做出不同判断的，是认知框架。
> 女娲提取的是认知操作系统。

## 诚实边界（每个 Skill 必写）

- 蒸馏不了直觉——框架能提取，灵感不能；
- 捕捉不了突变——截至调研时间的快照；
- 公开表达 ≠ 真实想法——只能基于公开信息。

## 生态与质量

- 已自带 14 个人物 + 1 个主题 Skill（Paul Graham / 张一鸣 / Karpathy / 乔布斯 / 马斯克 / 芒格 /
  费曼 / 纳瓦尔 / 塔勒布 等），全部基于 Agent Skills 协议，跨 runtime 通用。
- 保真度评分卡：15 个官方 Skill 全过独立双 Agent 盲测（立场一致性 / 风格辨识度 / 边缘诚实度 /
  来源透明度 / 结构完整度），全员 A 级（≥85 分）。
- 配套 **darwin-skill** 让 Skill 自动进化（8 维评估、棘轮机制只保留改进、独立子 Agent 评分）。

## 局限

- 只基于公开信息；对"没留下多少材料的人"效果差。
- SKILL.md 核心资产不接受外部 PR（治理集中）。
- runtime 覆盖 50+（含 CodeBuddy / Workbuddy），MIT。
